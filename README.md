# Projeto em desenvolvimento de software
Este é um projeto de controle financeiro pessoal. Ele permite o cadastro de usuários sem a necessidade de e-mail ou CPF.

## Tecnologias Utilizadas

O projeto é construído com as seguintes tecnologias:
Backend: Node.js com Express
Banco de Dados: SQLite
Frontend: JavaScript, Html, Css
Autenticação: bcryptjs e express-session

## Instalação e Execução

Certifique-se de ter o Node.js e o npm (ou yarn) instalados em sua máquina.

## 1. Clone o repositório (ou descompacte o arquivo).

## 2. Instale as dependências:

npm install
ou
yarn install

## 3. Inicie o servidor:

npm start
ou
npm run dev


## 4. O aplicativo estará acessível em http://localhost:3000 (ou a porta configurada no server.js)

4.
O aplicativo estará acessível em http://localhost:3000 (ou a porta configurada no server.js ).
